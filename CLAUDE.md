# Baia

## Rules

### Responsive

The whole site must be responsive and work at every screen size, from small phones (~360px) to wide desktops. Every UI change has to look right on mobile, tablet and desktop: no horizontal scrolling, no cut-off content, tap targets usable on touch. Check a UI change at phone (375px), tablet (768px) and desktop (1440px) widths before calling it done.

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `yarinohana10/baia`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: the glossary is `CONTEXT.md` at the root, and ADRs are in `docs/adr/`. See `docs/agents/domain.md`.
